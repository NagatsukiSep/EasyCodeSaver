# PCG Easy Code Saver

ポケカのデッキコードやテキストを名前付きで保存し、同期して使える Chrome 拡張です。

## 主な機能

- 選択テキストを右クリックから保存（名前入力）
- デッキコードをワンクリックで登録（デッキ結果ページ）
- 保存済みコードの一覧表示、コピー、名前変更、削除
- 保存したデッキコードを公式デッキページで開く
- `chrome.storage.sync` による同期

## 使い方

1. 拡張機能を読み込む
   - `chrome://extensions/` を開く
   - 「デベロッパーモード」を有効化
   - 「パッケージ化されていない拡張機能を読み込む」から本リポジトリを選択
2. 右クリックで保存
   - ページ上のテキストを選択 → 右クリック → 「選択テキストを保存」
3. デッキ結果ページで登録
   - `https://www.pokemon-card.com/deck/result.html/deckID/...` にアクセス
   - ボタン「拡張機能に登録する」から保存
4. ポップアップで管理
   - 一覧からコピー / 開く / 名前変更 / 削除

## 保存先

- `chrome.storage.sync`
- 同期が無効な環境ではローカル保存と同様の挙動になります

## 開発

- `manifest.json` の `content_scripts` がデッキ結果ページにボタンを挿入します
- `content.js` の `SRC_REGEX` を調整すると、初期の名前取得ロジックを変更できます
